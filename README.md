# Pixeload Portfolio

A responsive static portfolio website for Pixeload, featuring StringFlow and Hyper Pong.

## Included
- `index.html` — portfolio page
- `styles.css` — responsive styling
- `script.js` — navigation and footer behaviour
- `favicon.svg` — site icon
- `assets/stringflow-icon.png` — StringFlow icon
- `assets/stringflow-overview.png` — StringFlow product overview artwork
- `assets/stringflow-features.png` — StringFlow feature artwork

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `pixeload-portfolio`).
2. Upload the contents of this folder, including the `assets` folder, to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After deployment, open the URL GitHub Pages provides.
